# 폴짝폴짝 길건너기 — 로그인 버전

아이들이 **닉네임 + 숫자 4자리 비밀번호**로 들어가고, 코인·친구·펫·최고 기록이 서버(Firebase)에 저장돼요.
어느 컴퓨터나 태블릿에서 같은 닉네임으로 들어가면 같은 기록으로 이어서 놀 수 있어요.

- 진짜 이름이나 이메일은 받지 않아요. 닉네임은 Firebase 안에서만 쓰는 가짜 주소(`u…@pokjjak.game`)로 바뀌어 저장돼요.
- 비용: Firebase 무료 요금제(Spark)로 충분해요. 결제 카드 등록이 필요 없어요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `public/index.html` | 게임 전체 |
| `public/firebase-config.js` | **내 Firebase 프로젝트 값을 넣는 곳** (2단계에서 채워요) |
| `firestore.rules` | 저장소 보안 규칙: 자기 기록만 읽고 쓸 수 있어요 |
| `firebase.json`, `.firebaserc` | 배포 설정 |
| `tools/reset-pin.js` | 아이가 비밀번호를 잊었을 때 새로 정해 주는 도구 (선택) |

## 해야 할 일 (처음 한 번, 20분쯤)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가서 **프로젝트 만들기**.
2. 이름은 자유롭게(예: `pokjjak-game`). Google 애널리틱스는 꺼도 돼요.
3. 만들어지면 **프로젝트 ID**를 적어 두세요. (프로젝트 설정 → 일반에 있어요. 예: `pokjjak-game-1a2b3`)

### 2. 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭 → **이메일/비밀번호** → 첫 번째 스위치만 **사용 설정** → 저장.
   (아래쪽 "이메일 링크"는 끈 채로 두세요.)

### 3. 저장소 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)**, 시작 모드는 **프로덕션 모드**.
   (보안 규칙은 5단계 배포 때 `firestore.rules` 내용으로 바뀌어요.)

### 4. 웹 앱 등록하고 설정값 붙여 넣기
1. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`) 아이콘**.
2. 앱 닉네임을 적고 **앱 등록**. (Firebase Hosting 체크는 안 해도 돼요.)
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을
   `public/firebase-config.js`의 같은 자리에 그대로 옮겨 적으세요.
4. `.firebaserc`의 `YOUR_PROJECT_ID`를 1단계의 프로젝트 ID로 바꾸세요.

### 5. 인터넷에 올리기
Node.js(18 이상)가 깔린 컴퓨터의 터미널에서:

```bash
npm install -g firebase-tools   # 처음 한 번
firebase login                  # 브라우저가 열리면 같은 구글 계정으로 로그인
cd pokjjak-online               # 이 폴더로 이동
firebase deploy
```

끝나면 `Hosting URL: https://프로젝트ID.web.app` 이 나와요. **이 주소를 아이들에게 알려 주면 돼요.**

### 6. 확인
1. 그 주소로 들어가서 **처음이에요** → 닉네임과 비밀번호를 정해 가입.
2. 코인을 조금 모은 뒤, 다른 기기(또는 다른 브라우저)에서 같은 닉네임으로 **들어가기**.
3. 코인과 최고 기록이 그대로 보이면 성공이에요.

> 게임을 고친 뒤에는 `public/index.html`만 바꾸고 `firebase deploy`를 다시 하면 돼요.

## 운영하면서 쓰는 것들

**아이들 기록 보기** — Firestore Database → `players` 컬렉션. 문서 하나가 아이 한 명이고, `nickname`과 `save`(coins, best, owned, pets…)가 보여요.

**비밀번호를 잊었을 때** — 이메일이 없어서 "비밀번호 재설정 메일"은 쓸 수 없어요. 대신 `tools/reset-pin.js`로 새 번호를 정해 주세요. 기록은 그대로 남아요.
1. 프로젝트 설정 → **서비스 계정** → **새 비공개 키 생성** → 받은 파일을 `tools/service-account.json`으로 저장. (**이 파일은 절대 공유하지 마세요.**)
2. `cd tools` → `npm install` → `node reset-pin.js 폴짝왕 5678`

**랭킹** — 홈 화면과 게임이 끝난 화면의 **랭킹** 버튼으로 최고 기록 상위 50명을 볼 수 있어요. 기록은 Firestore의 `ranks` 컬렉션에 닉네임·최고 기록·고른 친구만 저장돼요. 로그인한 아이들끼리는 서로의 닉네임과 점수가 보여요.

**계정 지우기** — Authentication → 사용자에서 계정을 지우고, Firestore의 `players`와 `ranks`에서 같은 ID(UID)의 문서도 지워 주세요.

## 알아 둘 점
- **기존 Claude 링크의 기록은 옮겨지지 않아요.** 주소가 달라서 브라우저가 따로 저장하고 있었어요.
- **같은 닉네임으로 두 기기에서 동시에 놀면** 나중에 저장한 쪽 기록이 남아요.
- 코인 계산은 아이 브라우저에서 해요. 보안 규칙이 값의 모양과 범위는 막지만, 개발자 도구로 숫자를 바꾸는 것까지 완전히 막지는 못해요.
- 저장은 바뀐 내용을 1.5초마다 모아서 보내요. 무료 한도(하루 쓰기 약 2만 번)면 한 반이 함께 놀기에 넉넉해요.
- 닉네임에 진짜 이름을 쓰지 않도록 아이들에게 알려 주세요. 만 14세 미만 아이들의 개인정보에 관한 기준은 기관의 방침이나 전문가에게 한 번 확인해 두면 좋아요.
